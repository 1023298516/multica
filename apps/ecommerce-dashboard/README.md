# 淘宝 AI 运营首页原型

这是一个独立的电商专属首页原型，用于展示淘宝 AI 运营团队的老板视角总览。

当前版本只使用 mock 数据，不连接真实淘宝 API，不执行任何改价、退款、发货或库存写操作。

## 页面包含

- 今日核心数据：GMV、订单数、退款率、待发货、低库存 SKU、待审批事项
- 待老板审批：改价、库存、退款、商品优化等需要人工确认的事项
- 今日异常：订单、库存、售后、商品转化异常
- AI 员工状态：AI 店长、数据日报、商品优化、订单异常、库存补货、售后客服
- 商品优化建议：已有商品的标题、详情页、主图方向建议
- AI 店长日报摘要：今日风险和下一步动作

## 本地运行

从仓库根目录运行：

```bash
pnpm install
pnpm -C apps/ecommerce-dashboard dev
```

或者使用根目录脚本：

```bash
pnpm dev:ecommerce-dashboard
```

默认地址：

```text
http://localhost:3100
```

## 后续接入计划

1. 接 `taobao-api-service`：读取真实 GMV、订单、退款、库存和商品数据。
2. 接 Multica Issue：待审批、异常任务和 AI 员工状态跳转到对应 Issue。
3. 接 `taobao-mcp-server`：AI Agent 通过 MCP 查询淘宝 API。
4. 增加审批动作：所有高风险操作先进入审批，不直接执行。
5. 增加审计日志：记录审批人、AI 建议、执行参数和结果。
